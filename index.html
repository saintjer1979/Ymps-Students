步驟二：3 分鐘免費上傳到 GitHub 並發布網址（GitHub Pages）
  1. 1. 解壓縮檔案：將剛才下載的 index_html_github.zip 解壓縮，取出裡面的 index.html（注意檔名必須是全小寫 index.html）。
  2. 2. 建立 GitHub 專案庫（Repository）：登入 GitHub.com，點選右上角 「＋」➔「New repository」，在 Repository name 輸入名稱（例如：counseling-app），勾選 Public（公開） 與 Add a README file，然後點擊底部綠色按鈕 Create repository。
  3. 3. 上傳 index.html：進入剛建好的專案頁面，點選上方 「Add file」➔「Upload files」，把解壓縮出來的 index.html 拖曳放進框框內，等上傳進度條跑完後，點擊下方綠色按鈕 「Commit changes」。
  4. 4. 開啟 GitHub Pages 發布網址：點擊專案上方的 「Settings（設定）」 ➔ 左側選單找到 「Pages」 ➔ 在 Branch（分支） 下拉選單將 None 改為 main（或 master），按下旁邊的 「Save」。等待約 1～2 分鐘重新整理頁面，上方就會出現您的專屬網站網址！

💡 針對此互動的直接拆解法：王小宇 與 林小安 屬於「一方拿取或碰觸物品、另一方出手拉扯反擊」的連鎖衝突。建議先要求雙方手離開物品與對方身體，先把爭執物（如文具、材料）拿到老師手上保管，確認物歸原主或分開使用後，再分別聽雙方說，不要讓兩人在原位邊拉扯邊吵。
🎯 方式一：【先降溫拉開】最快穩住科任課堂秩序
適合雙方正在氣頭上、互不相讓，繼續講道理只會越吵越兇的當下。
1. 【先把人分開】：直接用平穩、簡短的話說：「現在兩個人先分開，甲坐講台旁，乙坐後面備用桌，手離開桌上的工具。」當下先不爭論誰先開始。
2. 【給具體動作冷卻】：不叫他「冷靜」，改給具體小動作：「先喝兩口水、趴著休息三分鐘，等呼吸慢下來老師再過去聽你說。」
3. 【讓全班繼續上課】：立刻轉向全班說：「大家繼續手上的進度，老師處理一下就好。」移開全班圍觀視線，當事學生才不會為了面子硬撐。
👤 針對【五年二班 7號 王小宇】（ADHD（注意力不足／過動衝動）、衝動控制較弱（先動手或先大聲回嘴））的直接做法：
指令一次只講短短一句（例如：「先把筆放桌上，人坐好」），當下不要連珠炮追問「為什麼要拿別人的東西」，他現在煞不住車，講越多越容易回嘴。
👤 針對【五年二班 14號 林小安】（自閉症／亞斯伯格（固著／人際直白）、感官敏感（怕吵雜／抗拒肢體碰觸））的直接做法：
他非常在意「自己的東西不能被亂碰」以及「原本講好的順序」，先直接講一句：「老師知道你的東西被拿走你不喜歡，老師現在幫你拿回來」，他確認東西安全後情緒就會降下來。 先請旁邊圍觀的同學轉頭繼續上課，給他衛生紙或喝水，輕聲告訴他：「先深呼吸三次，等不緊張了再慢慢跟老師說。」
